01

Motivation

Change is concentrated.

Most of the scene stays stable while attention concentrates on active content.

BOTTLENECK 01

Memory grows with every frame.

A 480P, 60-second rollout can use about 300GB of KV cache, versus 56GB for the model weights.

BOTTLENECK 02

Attention is not uniformly useful.

Stable backgrounds remain similar across frames. Only a small set of regions carries new visual information.

FIGURE 1 · CORE OBSERVATION

Most of a frame can be reused

Across camera panning and subject motion, the background changes slowly. High temporal cosine similarity marks tokens that can be reused. Concentrated attention identifies tokens that matter for the next step.

02

Method

One observation.
Three mechanisms.

DASA turns the observation into a unified design for memory, computation, and training.

01 · MEMORY

Keep dynamic history, refresh the rest

Historical KV tokens are pruned by layer-wise cosine similarity. The last frame of the previous chunk is kept as an anchor, and a static token is refreshed when its age reaches τ.

02 · COMPUTATION

Skip redundant denoising

Local w × w alignment compares the current chunk to the reference frame. Tokens with similarity ≥ γ exit early and reuse aligned features. Only dynamic regions continue through denoising.

03 · DISTILLATION

Do not train away motion

Static reuse can create a motion-lagging shortcut. DASA weights the DMD loss by W = 1 + α · max(0, 1 − sim), amplifying errors in high-motion regions.
